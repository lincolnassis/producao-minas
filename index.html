Produção por mina

Ver SQL deste gráfico
SELECT Unidade, SUM(realizado) AS realizado, SUM(meta) AS meta
FROM producao
GROUP BY Unidade
ORDER BY Unidade;

Paradas x produção

Ver SQL deste gráfico
SELECT Paradas,
       COUNT(*) AS dias,
       ROUND(AVG(realizado)) AS media_real,
       ROUND(AVG(meta)) AS media_meta
FROM producao
-- WHERE Unidade = 'Mina A'  (só entra se uma mina for escolhida)
GROUP BY Paradas
ORDER BY Paradas;
